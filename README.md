# Landing Page

Este proyecto es una landing page básica, creada como ejercicio de aprendizaje
de desarrollo web dentro de The Odin Project, específicamente después de
completar la unidad de CSS.

No es un producto propio ni representa un negocio real; es un proyecto
académico con fines de práctica.

## Tecnologías usadas

- HTML
- CSS
(JavaScript se implementará en el futuro)
